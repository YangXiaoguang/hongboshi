# 课程电商化转化研究与执行方案

> 目标：把课程平台从“内容浏览站”推进到“课程交易平台”，让用户先看到课程商品信息，并在课程路径、快速开始、课程列表和详情页任意位置都能顺手进入下单。

## 外部市场判断

- 中国用户已经形成成熟的移动电商心智。[CNNIC 第 57 次《中国互联网络发展状况统计报告》](https://www.cnnic.net.cn/NMediaFile/2026/0304/MAIN1772588317069TUXN3827X8.pdf)显示，截至 2025 年 12 月，中国网民规模达 11.25 亿，手机上网比例 99.6%，网络购物用户规模约 9.37 亿，占网民整体 83.2%。
- [国家统计局 2025 年 12 月社会消费品零售数据](https://www.stats.gov.cn/sj/zxfbhjd/202601/t20260119_1962323.html)表明，2025 年全国网上零售额 159722 亿元，其中实物商品网上零售额 130923 亿元，占社会消费品零售总额 26.1%。这说明用户对“在线看信息、在线决策、在线支付、立即获得权益”的路径已经高度熟悉。
- 课程虽然是非实物商品，但用户仍会沿用淘宝、天猫、京东、拼多多、抖音电商和微信小程序里的交易习惯：货架先行、价格显眼、权益清楚、优惠可见、信任凭证前置、购买按钮常驻、支付后立即获得可验证权益。

## 中国电商平台的关键转化特点

1. **移动优先与短路径决策**
   - 用户希望在首页、列表、推荐流、详情页都能直接行动。
   - 重要按钮通常在底部固定或卡片内前置，避免用户回到顶部找入口。

2. **货架化信息密度**
   - 商品卡片不仅展示图片和标题，还展示价格、优惠、销量/学习人数、权益标签、会员标签和主操作。
   - 课程平台对应为：课程封面、老师、主题、学习人数、价格、优惠券、免费/会员/已购状态、立即购买/开始学习。

3. **详情页承担信任建设**
   - 用户点击商品后必须马上看到“我买什么、多少钱、能得到什么、适不适合我、是否有保障”。
   - 心理课程比普通商品更需要适合人群、课程目录、学习成果、隐私保障、咨询衔接和老师信任背书。

4. **优惠与会员并行**
   - 中国电商常见单品购买、会员权益、优惠券、限时折扣并存。
   - 当前项目已有单课购买、成长会员、优惠券和支付保留时间，应继续强化“单买 vs 会员”的比较表达。

5. **下单弹层化**
   - 用户不应被迫跳转多层页面。常见做法是商品详情页内抽屉/半屏确认订单，展示商品、优惠、实付、支付方式、权益交付和订单状态。
   - 当前项目已有购买确认抽屉，本轮将其与课程货架入口打通。

6. **支付后即时履约**
   - 用户完成支付后要立刻看到权益到账和下一步入口。
   - 课程平台对应为：支付成功后展示“开始学习”“查看成长空间”，并将课程写入课程权益。

## 当前代码转化断点

- 课程货架主动作、列表内半屏下单、全局待支付召回和详情信任模块已完成，用户可以在课程中心、课程详情和成长空间继续支付或取消订单。
- 商品信任信息目前由课程详情确定性派生，尚未接真实评价、讲师资质库、售后政策配置和运营可编辑 FAQ。
- 优惠、会员价和路径组合预览已进入统一服务端营销规则快照；后台已支持规则暂停/恢复、持久化和审计，新增/编辑、库存与有效期仍待后续切片。
- 转化漏斗埋点已覆盖曝光、点击购买、创建订单、支付成功和开始学习等关键事件，后续需要进入运营报表和营销归因。

## CUX-A 本轮落地切片

- 课程路径里的重点课程增加主动作：免费/已购/会员可学显示开始学习或继续学习；未解锁课程显示立即购买或开通会员。
- 快速开始区增加主动作，用户在热门、免费、会员三个货架里可直接行动。
- 课程列表卡片价格区增加主动作，保留查看详情入口，同时让购买入口不再藏在详情页后半段。
- 从货架点击购买会进入 `/courses/:courseId?checkout=course|membership`，详情页自动打开购买确认抽屉。
- 免费或已解锁课程从货架点击主动作会直接进入学习页，并写入学习计划。

## CUX-B 本轮落地切片

- 将课程购买确认抽屉抽成 `CourseCheckoutDrawer` 共享组件，详情页和课程中心复用同一套下单、支付、取消和成功反馈。
- `/courses` 内点击“立即购买 / 开通会员 / 继续支付”会直接打开半屏结算抽屉，不再必须跳到详情页。
- 课程中心读取 `accessState.orders` 中的 `pending_payment` 订单，展示待支付召回条，包含商品、实付金额和支付保留时间。
- 课程卡片、课程路径和快速开始货架遇到既有待支付订单时，主动作显示“继续支付”，用户可以从任意货架位置回到支付动作。
- 详情页打开购买抽屉时也会优先召回既有待支付订单，避免重复创建订单。

## CUX-C 本轮落地切片

- 建立 `courseTrust` 纯模型，先用课程详情稳定生成评分、学习反馈、阶段完成率、讲师说明、内容审核点、售后/隐私口径和 FAQ，后续可替换为真实评价、讲师资质和售后配置。
- 课程详情页新增“购买信任”区，把讲师可信度、学习反馈、内容边界、权益交付、待支付取消、售后人工核实和隐私最小化前置到购买前。
- 交易面板新增评分、阶段完成率和信任摘要，让用户看到价格时同时看到学习反馈与可验证承接信息。
- FAQ 明确课程不替代咨询/治疗、支付后学习入口、阶段证明预览和支付异常处理，减少心理课程交易中的高风险误解。

## CUX-D 本轮落地切片

- 建立 `coursePendingCheckout` 纯模型，从课程权益状态统一生成待支付提示，避免课程中心、详情页和成长空间各自拼订单数据。
- 新增 `CoursePendingCheckoutBanner` 共享组件，支持横条、面板和内联三种形态，统一展示商品、实付金额、支付保留时间、继续支付和取消订单。
- 课程详情页会在当前课程存在待支付订单时展示召回提示；交易面板和移动底部购买条会把主动作改为“继续支付”。
- 成长空间 `/me/courses` 新增待支付课程订单面板，可直接打开共享结算抽屉继续支付，或取消待支付订单。

## CUX-E 本轮落地切片

- 建立共享 `coursePricing` 领域模型，课程订单、会员订单和前端结算摘要复用同一套标价、券额、直降、实付和节省金额计算。
- 新增 `coursePromotion` 纯模型，把课程直降、优惠券、限时折扣、会员替代方案和路径组合预览统一成可测试的展示契约。
- 课程卡片、快速开始区和详情页推荐卡开始展示券后价，减少用户从列表到下单前的价格落差。
- 课程详情新增“优惠与组合购”比较区，把单课购买、成长会员和路径组合预览并排展示，并明确组合购当前为价格预览。
- 购买确认抽屉新增“本单优惠”明细，展示已自动计入订单的课程直降、优惠券或会员年卡优惠。

## CUX-F 本轮落地切片

- 建立共享 `courseConversion` 领域契约，把曝光、详情点击、详情浏览、点击购买、打开结算、创建订单、支付成功和开始学习统一为稳定事件。
- 新增前端课程转化 analytics repository，支持本地队列、会话 ID、可选 analytics endpoint、发送成功/失败状态和失败保留。
- 课程中心记录货架曝光、路径/快速开始/发现区进入详情、主动作点击、结算打开、订单创建、支付成功和支付后学习启动。
- 课程详情记录详情浏览、推荐课程点击、交易面板/优惠区/信任区/移动购买条主动作、结算打开、订单创建、支付成功和学习启动。
- 事件 payload 统一带课程、路径、权益状态、结算模式、订单、支付渠道、价格和来源，为后续漏斗分析与营销后台提供数据基线。

## CUX-G 服务端营销规则路线

## CUX-G-A 本轮落地切片

- 建立共享 `courseMarketing` 规则契约，统一课程券、限时活动、会员活动价、路径组合购、规则状态、来源、作用范围、折扣方式和优先级。
- 服务端新增课程营销规则派生 Store，从已发布课程商品和系统规则生成当前规则快照，先保持只读，避免订单金额口径尚未切换前出现运营改价风险。
- 新增公共 `/api/course-marketing/rules`，前台课程货架、详情页、结算摘要和组合购展示可消费服务端活动规则。
- 新增后台 `/api/course-marketing/admin/rules` 与 `/admin/marketing` 只读控制台，运营可查看规则数量、生效状态、来源、折扣方式和作用范围。
- 前端 `coursePromotion` 与 `courseCheckout` 保留课程本地优惠 fallback；规则 API 失败时不影响浏览、下单和学习。

## CUX-G-B 本轮落地切片

- 将营销规则 Store 升级为“课程商品派生规则 + 状态覆盖层 + 审计事件”的结构，保持课程商品仍是真相源，同时允许运营暂停或恢复活动曝光。
- 新增开发期 JSON 持久化文件 `.hongboshi-data/course-marketing-rules.json`，保存规则状态覆盖和审计事件，重启后可恢复。
- 新增 `CourseMarketingRuleStatusUpdateRequestSchema`、`CourseMarketingAuditEventSchema` 和 `CourseMarketingRuleMutationResultSchema`，为后续规则编辑、库存、有效期和审计中心聚合预留稳定契约。
- 新增 `PATCH /api/course-marketing/admin/rules/:ruleId/status`，复用 `catalog:price` 权限，服务端校验目标状态、过期规则和重复操作。
- `/admin/marketing` 支持行级暂停/恢复、操作原因填写和最近审计展示；暂停后公共 `/api/course-marketing/rules` 不再输出该规则。

## 后续可维护升级路线

1. **CUX-G-C 路径包订单与权益交付**
   - 将路径组合购从价格预览升级为真实课程包订单，接入库存/有效期、订单金额、支付回调和课程权益批量交付。

2. **CUX-G-D 营销规则编辑与投放治理**
   - 在已完成状态持久化和审计基础上，补齐人工新增/编辑规则、优惠库存、有效期、适用人群、发布审批和审计中心聚合。

## 工程边界

- 前台只做购买意图与交易入口，不绕过课程权益和订单状态机。
- 是否能学习仍由 `resolveCourseAccess` 与服务端课程权益 API 决定。
- 支付成功后权益交付仍走现有 `course-access` 契约，避免产生第二套课程权益真相源。
- UI 只展示隐私友好的课程信息，不展示心理测评答案、咨询说明或风险原文。
