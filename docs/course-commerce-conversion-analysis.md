# 课程电商化转化研究与执行方案

> 目标：把课程平台从“内容浏览站”推进到“课程交易平台”，让用户先看到课程商品信息，并在课程路径、快速开始、课程列表和详情页任意位置都能顺手进入下单。

## 外部市场判断

- 中国用户已经形成成熟的移动电商心智。[CNNIC 第 57 次《中国互联网络发展状况统计报告》](https://www.cnnic.net.cn/NMediaFile/2026/0304/MAIN1772588317069TUXN3827X8.pdf)显示，截至 2025 年 12 月，中国网民规模达 11.25 亿，手机上网比例 99.6%，网络购物用户规模约 9.37 亿，占网民整体 83.2%。
- [国家统计局 2025 年 12 月社会消费品零售数据](https://www.stats.gov.cn/sj/zxfbhjd/202601/t20260119_1962323.html)表明，2025 年全国网上零售额 159722 亿元，其中实物商品网上零售额 130923 亿元，占社会消费品零售总额 26.1%。这说明用户对“在线看信息、在线决策、在线支付、立即获得权益”的路径已经高度熟悉。
- 课程虽然是非实物商品，但用户仍会沿用淘宝、天猫、京东、拼多多、抖音电商和微信小程序里的交易习惯：货架先行、价格显眼、权益清楚、优惠可见、信任凭证前置、购买按钮常驻、支付后立即获得可验证权益。

## 中国电商平台的关键转化特点

1. **移动优先与短路径决策**
   - 用户希望在首页、列表、推荐流、详情页都能直接行动。
   - 重要按钮通常在底部固定或卡片内前置，避免用户回到顶部找入口。

2. **货架化信息密度**
   - 商品卡片不仅展示图片和标题，还展示价格、优惠、销量/学习人数、权益标签、会员标签和主操作。
   - 课程平台对应为：课程封面、老师、主题、学习人数、价格、优惠券、免费/会员/已购状态、立即购买/开始学习。

3. **详情页承担信任建设**
   - 用户点击商品后必须马上看到“我买什么、多少钱、能得到什么、适不适合我、是否有保障”。
   - 心理课程比普通商品更需要适合人群、课程目录、学习成果、隐私保障、咨询衔接和老师信任背书。

4. **优惠与会员并行**
   - 中国电商常见单品购买、会员权益、优惠券、限时折扣并存。
   - 当前项目已有单课购买、成长会员、优惠券和支付保留时间，应继续强化“单买 vs 会员”的比较表达。

5. **下单弹层化**
   - 用户不应被迫跳转多层页面。常见做法是商品详情页内抽屉/半屏确认订单，展示商品、优惠、实付、支付方式、权益交付和订单状态。
   - 当前项目已有购买确认抽屉，本轮将其与课程货架入口打通。

6. **支付后即时履约**
   - 用户完成支付后要立刻看到权益到账和下一步入口。
   - 课程平台对应为：支付成功后展示“开始学习”“查看成长空间”，并将课程写入课程权益。

## 当前代码转化断点

- `/courses` 已有课程路径、快速开始区和课程列表，但这些位置主要是“查看详情”，缺少明确的“立即购买/开通会员/开始学习”主动作。
- `CourseCard` 价格区只有箭头，用户需要先猜测“点卡片进入详情，再找购买区”，不符合电商货架的直接行动习惯。
- `CourseStarterLanes` 和 `CoursePathSection` 很靠前，但只展示价格，不提供下单入口。
- `/courses/:courseId` 已有交易面板、购买确认抽屉和移动端底部购买条，但无法从列表带着购买意图进入并自动唤起抽屉。

## CUX-A 本轮落地切片

- 课程路径里的重点课程增加主动作：免费/已购/会员可学显示开始学习或继续学习；未解锁课程显示立即购买或开通会员。
- 快速开始区增加主动作，用户在热门、免费、会员三个货架里可直接行动。
- 课程列表卡片价格区增加主动作，保留查看详情入口，同时让购买入口不再藏在详情页后半段。
- 从货架点击购买会进入 `/courses/:courseId?checkout=course|membership`，详情页自动打开购买确认抽屉。
- 免费或已解锁课程从货架点击主动作会直接进入学习页，并写入学习计划。

## 后续可维护升级路线

1. **CUX-B 列表内半屏下单**
   - 将 `CheckoutDrawer` 抽成复用组件，在 `/courses` 直接完成创建订单、选择支付方式和支付确认，不再必须进入详情页。

2. **CUX-C 商品信任模块**
   - 补课程评价、老师资质、学习成果案例、常见问题、退款/售后口径和隐私说明，形成心理课程购买决策闭环。

3. **CUX-D 待支付订单召回**
   - 在课程中心、详情页和成长空间展示待支付订单，支持继续支付、取消订单和支付保留倒计时。

4. **CUX-E 优惠与组合购**
   - 建立可维护的优惠券、限时折扣、会员价、课程包和路径包契约，避免把营销规则散落在 UI 组件里。

5. **CUX-F 转化漏斗埋点**
   - 记录曝光、点击详情、点击购买、创建订单、支付成功、开始学习等事件，后台按课程、路径、价格和来源分析转化。

## 工程边界

- 前台只做购买意图与交易入口，不绕过课程权益和订单状态机。
- 是否能学习仍由 `resolveCourseAccess` 与服务端课程权益 API 决定。
- 支付成功后权益交付仍走现有 `course-access` 契约，避免产生第二套课程权益真相源。
- UI 只展示隐私友好的课程信息，不展示心理测评答案、咨询说明或风险原文。
